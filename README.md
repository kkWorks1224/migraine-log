# 頭上注意

開いた瞬間にメモでき、フリックで状態を動かすモバイルファーストの偏頭痛記録 Web アプリ。

**公開URL:** https://migraine-log.kkworks1224.workers.dev

## できること

- **すぐ書ける**：開くと入力欄にフォーカス。Enter で記録（その時刻・現在地の気圧と天気を自動で添付）
- **入力欄の下のツール**：始まった時刻／強さ（軽い・中くらい・強い）／薬／寝不足／きっかけ／症状
- **✦ AI 整理**：音声入力のメモ（誤変換を含む）を Workers AI が読み取り、強さ・薬・寝不足・きっかけ・症状・時刻を埋める
- **フリックで状態管理**

  | 操作 | 痛い | 和らいだ | 治まった |
  |---|---|---|---|
  | 右へフリック | → 和らいだ | → 治まった（終了時刻を記録） | → 削除 |
  | 左へフリック | → 削除 | → 痛い | → 和らいだ |

  丸ボタンで即「治まった」、カードをタップで詳細編集。すべてトーストから取り消し可能
- **気圧カード**：現在地の気圧・3 時間／24 時間の変化・天気・気温・湿度と、24 時間前〜24 時間後の気圧グラフ。急な低下区間（3 時間で 1.5hPa 以上）をオレンジで強調し、この先の低下時刻を表示
- **まとめ**：月カレンダー（強さで色分け・服薬日に印）、頭痛日数・服薬日数・平均の強さ・平均持続時間、きっかけ／時間帯の内訳、薬ごとの効いた割合
- **薬の使いすぎ注意**：服薬が月 10 日以上で警告（国際頭痛分類 ICHD-3 の薬剤の使用過多による頭痛の基準を参考）
- **AI の見立て**：直近 90 日の記録から傾向を箇条書きで要約
- **CSV 書き出し**：受診時に渡せる頭痛ダイアリー（Excel で開ける BOM 付き UTF-8）
- **気圧の注意予報**：この先 48 時間で頭痛に注意が必要な気圧の低下を「明日 14時ごろから（6時間で −2.4hPa）」の形で表示。注意の度合いは高・中・低
- **週間予報**：7 日先までの天気・最高/最低気温・降水確率と、気圧の注意が必要な日。気圧グラフは「2日 / 1週間」を切り替え
- **あなた専用の基準**：頭痛の日が 5 日・2 週間分たまると、過去 92 日の気圧と記録を突き合わせ、頭痛が出やすい下がり方（6 時間で何 hPa か）を自動で見つける。関係がはっきりしない人には大きな低下だけを出す
- **プッシュ通知**：この先 12 時間に注意が必要な低下があれば 7〜22 時に通知（iPhone はホーム画面に追加したアプリで iOS 16.4 以降）
- **今日は頭痛なし**：頭痛のなかった日を 1 タップで記録（分析の精度を上げるため）
- **前ぶれ**：あくび・首や肩のこり・眠気など、頭痛の前に出るサインを記録
- **服薬日数のその場表示**：薬を記録すると「今月の服薬 9日目」と表示し、月 10 日に近づくと注意
- **生活への支障度（MIDAS）**：過去 3 か月の支障を 5 問で点数化し、前回と比較
- **受診用レポート**：直近 3 か月の集計・支障度・気圧との関係・今月の記録を A4 1 枚に（印刷・PDF）
- **Siri で音声記録**：ショートカットから `/#memo=話した内容` を開くとそのまま記録（ログイン中は AI で整理してから）。本文はサーバに送らない URL フラグメントで受け取る
- **未ログインでも使える**：記録は端末に即保存。Google でログインすると端末間同期と AI 機能が有効になり、それまでの記録もアップロード

### 偏頭痛管理として追加した項目と理由

| 項目 | 理由 |
|---|---|
| 強さ（3 段階） | 頭痛ダイアリーの標準項目。素早く選べるよう 0–10 ではなく 3 段階 |
| 終了時刻・持続時間 | 片頭痛の診断（4〜72 時間）や治療効果の判断に使われる |
| 症状（前兆・吐き気・光／音過敏・拍動性・片側・動くと悪化） | ICHD-3 の片頭痛の診断基準に含まれる特徴 |
| きっかけ（天気・ストレス・生理・空腹・アルコール等） | 誘因の把握は予防の基本 |
| 薬の効き目 | 急性期治療薬が合っているかの判断材料 |
| 服薬日数の警告 | 薬の使いすぎによる頭痛は頻度が高く、気付きにくい |
| 気圧の 3 時間・24 時間変化 | 気圧の絶対値より「下がり方」が頭痛との関係で注目されるため |
| CSV 書き出し | 医師に記録を見せやすくする |
| 頭痛なしの日 | 頭痛のない日が分からないと、気圧との関係（起きた日と起きなかった日の比較）が正しく出せない |
| 前ぶれ（予兆） | 片頭痛の多くに数時間〜1日前の予兆があり、早めの服薬の判断に使える |
| MIDAS | 頭痛外来で使われる生活支障度の標準的な指標。治療効果を数字で追える |

## 構成

```
index.html          入力欄と全画面スケルトンを静的 HTML で持つ（JS 読み込み前から入力可）
src/
  Composer.tsx      入力欄の振る舞い・ツールバー・AI 整理
  EntryCard.tsx     フリック操作
  PressureCard.tsx  気圧カード（SVG グラフ）
  EntrySheet.tsx    詳細編集シート
  StatsSheet.tsx    まとめ（カレンダー・集計・AI・CSV）
  store.ts          ローカルファースト同期ストア（localStorage + /api/sync 差分同期）
  weather.ts        位置情報・気圧系列・記録時点のスナップショット計算
  types.ts          クライアント／Worker 共通の型と選択肢
worker/index.ts     Cloudflare Worker（Hono）: Google OAuth / 同期 / 気象プロキシ / Workers AI
migrations/         D1 スキーマ
public/sw.js        アプリシェルのキャッシュ（2 回目以降はネットワークを待たずに表示）
```

## 技術選定理由

| 技術 | 理由 |
|---|---|
| **Cloudflare Workers（Static Assets）** | 画面と API を 1 つの Worker で配信。エッジ実行で初回表示が速く、Pages との二重管理が不要 |
| **D1** | Workers から直接使える SQLite。記録本体は JSON 列に持ち、同期・集計に使う列（開始時刻・更新時刻・削除）だけを取り出すことで、項目追加時にマイグレーション不要 |
| **Workers AI（Llama 3.3 70B fp8-fast）** | 指示どおり Cloudflare 内で完結。日本語の誤変換補正と JSON 出力が安定し、応答が速い（約 1〜2 秒）。メモ整理と傾向要約の 2 用途に使用 |
| **Workers Rate Limiting + D1 カウンタ** | AI は 1 ユーザー 10 回/分・100 回/日、気象 API は IP あたり 60 回/分に制限し、コストと濫用を抑える |
| **Open-Meteo（Worker 経由）** | API キー不要で、過去 92 日までの毎時の気圧が取れる（記録時刻を後から変えても当時の気圧を引ける）。届かない場合は MET Norway（現在以降のみ）に自動で切り替え |
| **Nominatim（逆ジオコーディング）** | 地名表示用。Cache API で 30 日キャッシュし、利用規約の頻度制限内に収める |
| **Cache API** | 気象データを位置×時間単位で 1 時間キャッシュし、外部 API 呼び出しを最小化 |
| **位置の丸め（小数 2 桁 ≒ 1km）** | 外部 API に渡す位置情報を必要最小限にする |
| **Hono** | Workers 向けの軽量ルーター。Cookie・セキュリティヘッダー等のヘルパーが揃い依存が小さい |
| **Google OpenID Connect（自前実装・ID トークン方式）** | Google のみなので認証ライブラリや外部 IdP サービスは不要。ID トークンを Google の公開鍵（JWKS）で署名検証するため**クライアントシークレットを保管しなくてよい**（漏えいリスクとローテーション作業がない）。state・nonce で CSRF／リプレイを防止し、セッションは D1 にハッシュ保存した HttpOnly Cookie |
| **React 19 + Vite + @cloudflare/vite-plugin** | `vite dev` 1 つで UI と Worker（workerd）を同時に動かせ、本番と同じランタイムで検証できる |
| **Motion（旧 Framer Motion）** | スプリング物理・ドラッグ・レイアウト／exit アニメーション・SVG の線描画が揃い、iOS らしい慣性のある操作感を少ないコードで実現 |
| **素の CSS（backdrop-filter）** | Liquid Glass の半透明・ぼかし・彩度・縁のハイライトを細かく調整するため UI ライブラリは使わない。色は Apple のシステムカラー、タップ領域は HIG の 44pt 以上 |
| **気圧の判定に 24 時間移動平均** | 気圧は潮汐で 1 日 2 回、1〜3hPa 自然に上下する（甲府・東京では「3 時間で 2hPa 以上下がる」日が半数以上）。そのままでは毎日「低下」と判定されるため、24 時間移動平均で日内の上下を除き、低気圧などによる下がり方だけを 6 時間あたりの変化で見る |
| **Web Push（VAPID・自前実装）+ Cron Triggers** | 通知サービスを追加せず Cloudflare 内で完結。Workers で動かない Node 向けライブラリの代わりに、RFC 8291/8292 の暗号化と署名を Web Crypto で実装。Cron で 1 時間ごとに購読者の地点の予報を確認する。購読先はブラウザのプッシュサービスのホストだけを許可（SSRF 対策）、位置は約 10km に丸めて保存 |
| **SVG 手書きのグラフ** | 気圧グラフ 1 枚のためにチャートライブラリ（数十〜百 KB）を入れない |
| **ローカルファースト（localStorage）＋差分同期** | 「開いた瞬間メモ」のため保存は即ローカル、同期は裏で後勝ちマージ。オフラインでも記録できる |
| **静的 HTML の入力欄** | React の読み込みを待たずに入力できる。下書きはインラインスクリプトで保存 |
| **Service Worker** | 2 回目以降はキャッシュから即表示（stale-while-revalidate） |
| **iOS ハプティクス（`<input switch>`）／Vibration API** | フリックの閾値通過・確定時などに触覚フィードバック |

## 開発

```bash
npm install
npm run db:migrate:local
npm run dev            # http://localhost:5174 （/auth/dev で開発用ログイン）
npm run deploy
```

`.dev.vars`（git 管理外）: `DEV_LOGIN=1`、`VAPID_PRIVATE_JWK=…`（通知の署名鍵。本番は `wrangler secret put VAPID_PRIVATE_JWK`）

ローカルで通知の Cron を手動実行: `/auth/dev/cron`（開発ログイン有効時のみ）

Google ログインにシークレットは不要。Google OAuth クライアント（`wrangler.jsonc` の `GOOGLE_CLIENT_ID`）の承認済みリダイレクト URI に `https://<host>/auth/callback` を登録する。

## セキュリティ

- 認証: Google OpenID Connect（ID トークンを JWKS で RS256 署名検証、iss・aud・exp・nonce・state を検証）。セッショントークンは SHA-256 ハッシュのみ D1 に保存、Cookie は HttpOnly / Secure / SameSite=Lax
- 認可: 記録の主キーは `(user_id, id)` で、他ユーザーの行は読み書き不可。受信データはサーバ側で検証・正規化（未知のキーは破棄）
- ヘッダー: CSP（インラインスクリプトはハッシュ許可のみ）、frame-ancestors 'none'、HSTS、nosniff、Permissions-Policy で位置情報は自オリジンのみ
- CSRF: SameSite=Lax Cookie に加え、状態を変える POST は Origin / Sec-Fetch-Site が自オリジンのときのみ受け付ける
- 濫用対策: 本文 5MB 上限、配列入力の件数上限、同期は 1 ユーザー 120 回/分、地名取得（Nominatim）はアプリ全体で 60 回/分
- ログアウト時に端末の記録と下書きを消去（共用端末対策）
- CI はリポジトリ読み取り権限のみ
- `/auth/dev` は `DEV_LOGIN=1` かつ localhost のときのみ有効

※ 本アプリは記録と傾向把握のための道具であり、診断や治療の判断は医師に相談してください。
